# 08 — JSON and API Integration

## What Is JSON?

JSON stands for JavaScript Object Notation.

It is a text format used to exchange structured data.

## Why Atlas Uses JSON

The C++ engine calculates financial results.

The React frontend needs those results in a
format it can read and display.

JSON provides that exchange format.

## Current Data Flow

```text
C++ Portfolio Simulator
        |
        v
Performance Analyzer
        |
        v
PortfolioJsonExporter
        |
        v
demo_portfolio.json
        |
        v
React Data Parser
        |
        v
Portfolio Dashboard
```

The JSON file is currently generated by the C++ demo
and copied into the frontend as a static fixture.

## JSON Schema Version

Atlas currently exports schema version 1.

Important fields include:

- strategy
- initial_capital
- final_equity
- net_profit
- total_return_pct
- maximum_drawdown_pct
- equity_curve
- trades

## Why Schema Versions Matter

A schema version identifies the expected structure
of exchanged data.

It helps clients detect incompatible changes.

## Runtime Validation

The frontend validates received JSON before
using it to render financial information.

Invalid numbers, malformed trades, unsupported
schema versions, and inconsistent final equity
are rejected.

## Future Backend API

A future backend will accept validated backtest
configurations and invoke the C++ engine.

The initial public API should enforce resource limits,
input validation, timeouts, and request isolation.

This API has not yet been implemented.
